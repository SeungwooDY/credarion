# Changelog — 2026-07-28

Engine now matches on unit price only (never line totals), the mismatch UI
drops the total-price columns, and the site favicon was replaced with the new
Credarion mark.

## Engine: unit-price-only matching

Line totals (amounts) are derived numbers that SGWERP and supplier systems
round differently, so an amount gap with equal quantity and unit price was
pure noise ("amount_mismatch"). Amounts no longer influence any match verdict:

- Layers 1/2/4 (`exact_match._classify_discrepancy`): the `amount_mismatch`
  classification is removed — only quantity and unit-price deltas flag a
  discrepancy. `amount_delta` is still computed and stored, but it is
  informational only (money-at-risk sums, exports).
- Layer 3 (`multi_delivery._classify_group`): the group gate is now quantity
  total AND **average unit price** (group amount ÷ group qty) within the price
  tolerance, instead of the summed amount totals. Price-drift groups
  (`price_inconsistent`) are unchanged.
- Layer 3.5 (`aggregate_match`): both passes gate on qty OR avg unit price;
  the `amt_tolerance_pct` parameter is gone.
- AI layer prompt now says "matching quantities or unit prices".

Historic DB rows with `discrepancy_type="amount_mismatch"` still render (the
UI label map keeps the key); new runs never produce it.

## Mismatch UI: total-price columns removed

Per Richard: unit price is the source of truth, total price is derived.

- Main mismatches table: ERP Amt / Stmt Amt / Amt Delta columns removed;
  a Price Delta column added after ERP Price / Stmt Price.
- Spreadsheet view: `erp_amount` / `stmt_amount` / `amt_delta` grid columns
  removed; delta recompute now only handles qty and unit price.
- Backend `/reconciliation/mismatches` payload unchanged (amounts still
  returned for export/consumers).

## Why the deltas looked like a "copy paste of the statement quantity"

Not a bug: on aggregation-group rows the group verdict lands on the
surplus-side leftover line (2026-07-13 change). When a supplier statement line
has no GRN at all inside its group, the group delta *is* that line's full
quantity/amount — i.e. the supplier billed a delivery the ERP never received,
so delta == statement qty by construction.
